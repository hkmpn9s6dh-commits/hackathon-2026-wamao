# 闸 D：同题多版盲排（替代做法）

## 为什么替代

这是一场**首届**赛事，没有往届得奖作。按中枢候选 `C-20261114-d5b25111`（AME-1381 的教训）：
抓机构官网首页当尺子不成立，因为画幅与媒介不对等。

本次试过、但没拿到的同类获奖作整屏图：

| 来源 | 结果 |
| --- | --- |
| 站酷（zcool.com.cn）瓦猫相关作品 | 搜到了，但 CDN 403；Web 端弹"访问验证"滑块，人工才能过 —— 不绕 |
| Behance | 403 |
| 数字武当杯（最近的一届同类 IP 视觉赛） | 获奖公示要到 12 月底才出 |
| 站酷 / 美图秀秀赛获奖页 | 同样在站酷域内，同上 |

于是按既定替代方案走 **C 案：同题多版盲排**——同一件作品的三种版式，随机字母，两位评委各自排名。

## 第 1 轮

三位候选：`C`＝纸本竖排（`src/99-varB.html`）、`A`＝上图上字（`src/99-varC.html`）、`B`＝满版压字（`src/01-hero.html`）。
出图后缩到 900px 宽，随机字母，映射见 `mapping.txt`。

- 评委一（reasoning 档）：**1 = A，2 = B，3 = C**
  - A：「大标题与烟云互相呼应，版面克制、层级清晰」／「下半页留白偏多，右侧小注字号小」
  - B：「满版画面带来最强视觉冲击，右侧过去/现在/未来竖排标注巧妙」／**「白字压在发亮的瓦片上，标题对比不够，可读性差」**
  - C：「竖排汉字配印章红，设计气质最浓」／「'主视'红标像没清掉的制作标注，中部大片空洞」
- 评委二（lite 档）：**1 = B，2 = A，3 = C**
  - B：「满版图加压在画面上的大字，冲击力最强」／**「白字压在云和瓦面上，局部对比不够，阅读略吃力」**
  - A：「米白底加细红线，编辑感最考究」／「下三分之一空得没理由，像两张纸拼的」
  - C：「左字右图加红色印章，版式最有设计态度」／「图被缩成小块，瓦猫气势尽失」

**共同点**：两版并列（A/B 各得一票第 1），且两位都点到 B 的同一个毛病——**压在画面上的白字对比不够**。

## 第 2 轮（改做法：把 B 的结构与 A 的字区合并）

`D` = 满版图 + 纸面字区 + 右缘时间轴（`src/99-varD.html`）。

- 评委一：1 = B，2 = A，**3 = D**；D 的问题：「下半版略松散，右栏小字孤悬，整体重心偏上」
- 评委二：1 = A，2 = B，**3 = D**；D 的问题：「标题缩小后失去视觉重量，右侧竖排标记悬空」

## 结论（两轮就停）

按「同一道题改做法两轮还没过，停下来定」的规矩，此处不再改版式，理由与取舍：

1. 两轮里 **B（满版）与 A（上图上字）稳定占据前二，D（折中）两轮都垫底**——折中把两边的长处互相抵消了，这条是要记下来的。
2. 定稿取 **B**：它在两轮里各拿过一次第 1、一次第 2（平均 1.5，与 A 并列），且是两位评委都主动夸"冲击力／电影感"的那一版；同时它是唯一能承载"云从口里升起、接到天上"这一记忆点的构图（A 把图压成横幅，云接不到天）。
3. 两位评委对 B 的同一处批评**已经修掉**：标题与正文所在的横带加玻璃带（3px 模糊 + 0.82 亮度、上下 26%/74% 淡出），正文提亮到 `#ECE6D8`，标题加 30px 柔和阴影。修后即成 `output/01-hero.png`。
4. A 的形态没有丢——它的"纸 + 字区"做法被 02、03 两张沿用，一套三张因此有统一语汇。

**闸 D 判定：条件性通过。** 通过的是"同题多版里选对了构图"，不是"压过了五件往届得奖作"——后者这场比赛没有材料可做。留给用户的一句话：若你在站酷/小红书上看到同类赛的获奖作品，可以发我 5 张，我按正式口径再盲排一次。
