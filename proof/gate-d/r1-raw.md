# 第 1 轮盲排原文（2026-11-15）

映射：A = 上图上字（varC）｜B = 满版压字（01-hero 原版）｜C = 纸本竖排（varB）

## 评委一（reasoning）

排名：1. A ｜ 2. B ｜ 3. C

A（第1）
- 最强项：大标题与烟云互相呼应，版面克制、层级清晰
- 最弱项：下半页留白偏多，右侧小注字号小，不易读

B（第2）
- 最强项：满版画面带来最强视觉冲击，右侧"过去/现在/未来"竖排标注巧妙
- 最弱项：白字压在发亮的瓦片上，标题对比不够，可读性差

C（第3）
- 最强项：竖排汉字配印章红，设计气质最浓
- 最弱项："主视"红标像没清掉的制作标注，中部大片空洞

只留一张：A。完成度最高，字、图、白都在控制内，能直接送印；B 靠图撑住，C 版式没收住。

## 评委二（lite）

排名：B 第 1，A 第 2，C 第 3

B
- 最强项：满版图加压在画面上的大字，冲击力最强，"过去—现在—未来"竖标点题准。
- 最弱项：白字压在云和瓦面上，局部对比不够，阅读略吃力。

A
- 最强项：米白底加细红线，字距干净，编辑感最考究。
- 最弱项：下三分之一空得没理由，标题与画面像两张纸拼的。

C
- 最强项：左字右图加红色"主视"印章，版式最有设计态度。
- 最弱项：图被缩成小块，瓦猫气势尽失，下半页近乎空场。

只留一张：B。它是唯一一张"图说话、字也说话"的，题材势能和过去／现在／未来的概念都在一屏内立住；A 太静，C 像内页。
