# 一口云 · 望见云首届瓦猫 AI 创作大赛（AI 设计 · 专业组）

> 瓦猫只做一件事：把外面的东西，变成屋里的东西。
> 过去它吞风、吞灾；现在它蹲在云下面，还是那张嘴。

三张 A4 竖版（2480×3508 / 300dpi）设计稿 + 一份 100–300 字创作说明。

| 图 | 讲什么 |
| --- | --- |
| `output/01-hero.png` | **主视觉**：瓦猫蹲在青瓦屋脊端头，口中涌出一条云，云升到天上去 |
| `output/02-craft.png` | **工艺考据**：胎、火、脊——它不是塑像，是瓦 |
| `output/03-future.png` | **未来概念**：云口可换、云腹是窑、云瓦归还 |

## 复验（一条命令）

```bash
npm ci                       # 只装 playwright 包，浏览器用本机已装的 chromium
bash scripts/verify.sh       # 重出三张 + 量尺寸/DPI/体积 + 数字数
```

`verify.sh` 里，`render.mjs` 是 **fail-closed** 的：字体没加载、文字溢出、出安全区、
文字压到图上、字号小于 24px —— 任一不满足就**拒绝出图**并退出 1。

## 关键决定

1. **不改"位"，只换"吞"**：现存的瓦猫文创几乎都在改形，很少改位置；而瓦猫的功能是由位置定义的。
   于是把"最高处"从瓦脊换成设备层与云，故事就能接着讲。
2. **三张图分工**：一张负责第一眼（场景），一张负责可信（工艺考据，含出处），一张负责想象（概念与色票）。
3. **概念图把"釉"当证据**：吞进去的是云，烧出来的是釉，釉色票给了 4 个可核对的色值——比再画一张效果图诚实。
4. **版式自己写**：不用模板站，四类断言每次出图都跑；被否掉的三个版式留在 `src/99-var*.html` 并在 `proof/gate-d/` 里写明为什么被否。
