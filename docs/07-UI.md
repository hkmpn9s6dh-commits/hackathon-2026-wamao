# 07-UI：风格、尺子、记忆点、主屏规格

## 1. 风格预设

| 项 | 取值 |
| --- | --- |
| 底色 | 云白 `#F4F1EA`（纸）／画面满版时用图自身的青灰 |
| 主文色 | 墨 `#23231F`，次级 `#5A574E` |
| 点缀 | 朱 `#A63A2B`（只用在一条 6–7px 的横线和一个"01/03"式的索引上） |
| 陶土 | `#A9613C`（只出现在色票与编号） |
| 云青 | `#6E8C7B`（只出现在色票与概念图的釉色） |
| 字 | 标题 Noto Serif SC 500；正文 Noto Serif SC 300；标签与编号 Noto Sans SC 400 |
| 字号阶（300dpi） | 300 / 132 / 96 / 64 / 56 / 44 / 40 / 34 / 32 / 25 |
| 网格 | 12 栏，版心 2120（左右各 180），栏距 40 |

**为什么是纸 + 朱线**：这是一件讲"瓦"的东西，纸与陶土最接近它的材质；朱线只用来切分"图"与"字"，不做装饰。

## 2. 尺子（开工前读的参照）

首届赛事，没有往届得奖作。按中枢候选 `C-20261114-d5b25111` 的替代做法，尺子改用**同题材的专业设计物**与**实物形制**两类，各自负责一件事：

| # | 参照 | 学哪一点 |
| --- | --- | --- |
| 1 | 鹤庆瓦猫实物（政府/媒体图，见 `01-CULTURE.md` 出处） | 形制不许走样：头大过身、巨口、王字、青灰素胎 |
| 2 | 剑川黑陶瓦猫 | 材料气质可以整片黑下去；本作不取，但要确认"青灰"是有意选择 |
| 3 | 望见云官方征稿文案与"故事种子" | 语气：不炫技、不喊口号，从具体物件讲起 |
| 4 | 博物馆文创的"器物 + 考据"版式惯例 | 考据页的三段式：实物图 / 分解注 / 出处 |
| 5 | 海报类作品的"图占 2/3、字占 1/3"分栏 | 主视觉的图字比 |
| 6 | 传统器物的色票写法（素胎 / 釉 / 火痕） | 概念页用色票替"效果图说话" |

## 3. 记忆点（唯一）

**一张开到极限的口，加一条从口里升起、接到云上的线。** 三张图各自复用它一次：主视觉是云，考据是"腹中空"，概念是"吞进云、吐出釉"。

## 4. 主屏规格（主视觉 01）

- 画布 2480×3508；图片满版，上半部为图，标题与正文压在画面下三分之一。
- 标题「一口云」300px，字距 0.09em，白色，居中偏左；标题下压一条 620px 的细线。
- 正文三行，40–46px；右下角两行元信息，25px。
- 右缘一条 2px 竖线（y 380–3120）+ 三个刻度：未来 / 现在 / 过去，33px 竖排。
  **云从口里往上飘，时间就往上走**——刻度不是装饰，是把"过去现在未来"落在画面上的唯一装置。
- 可读性：标题与正文所在的横带加一层 3px 模糊 + 0.82 亮度的玻璃带，边缘用 26%/74% 的蒙版淡出；正文色提到 `#ECE6D8`。

## 5. 量测口径（只管卫生，不判好坏）

`node scripts/render.mjs` 每次出图前跑四类断言，任一不过就**拒绝出图**：

1. 字体真的加载（`document.fonts.check`，防止静默回落到系统字体）
2. 标了 `data-fit` 的文字块不溢出容器（±1px）
3. 标了 `data-safe` 的元素留在 120px 安全区内
4. 标了 `data-noimg` 的文字不与任何图片相交（图片按其裁切祖先盒计算，避免 `transform: scale` 的假报）
5. 正文字号 ≥24px；图片必须解码成功

`python scripts/check_output.py` 再量：尺寸 / 300dpi / RGB / 单张 ≤20MB。
